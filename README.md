# 显生宙大陆风化交互数据库（公开版）

该目录是面向 GitHub Pages 的公开交互版，仅包含图 1（A–C）和图 2（A–C）。它不发布样品详情、文献名称、原始主量元素数据、坐标明细、筛选/排除记录或数据库重建功能。

## 使用方法

1. 打开页面后，默认显示图 1；右上方可切换至图 2。
2. 图 1A 与图 1B–C 分开显示，以便分别缩放和平移。
3. 图 2 可在 2A、2B、2C 间切换。
4. 滚轮或触控板可缩放，按住图件可平移；各区块的“重置图件视图”可恢复初始视野。

## 页面结构

- `index.html`：公开交互页面。
- `data/*.json`：仅供绘图的匿名 Plotly 图层；不含鼠标悬浮详情、样品 ID、文献名或管理信息。
- `build_public_dashboard.py`：在私有项目环境中更新公开绘图层的构建脚本；不需要在 GitHub Pages 中运行。

本公开前端通过 GitHub Pages 静态托管，不依赖外部数据库服务。
